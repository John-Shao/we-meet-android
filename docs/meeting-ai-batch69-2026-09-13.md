# 第 69 批：独立录音控制与音频分片协议

新增 CaptureApi、DTO、CaptureRepository 与 PCM WAV 编码／校验。固定路径覆盖创建、状态、设备命令、分片上传、回执分页和封存；创建／命令使用调用方已保存的 Idempotency-Key 与设备租约。当前状态和历史操作结果分别保留，重放不会将旧 result 当成 capture 当前状态。

音频约束与后端一致：真实 16 kHz 单声道 PCM16、完整毫秒、每片 1 ms 至 10 s；最多 4,320 片、12 小时、32 MiB 待上传缓冲预算。编码器不负责重采样，后续采集必须实际取得 16 kHz 音频。上传前冻结字节并校验 WAV 和 SHA-256；仅 stored=true 且全部元数据精确匹配的回执可确认本地片段。

录音／笔记专用 HTTP 客户端禁用重定向、缓存、自动连接重试及日志，总调用时限 20 秒。租约不进 URL，创建 DTO 的字符串表达不包含租约或标题。账户切换后不接纳旧响应；取消仍向上抛出。仅文字模式仍未开放。

验证：9 项新增 CaptureRepository JVM 测试和 16 项笔记仓库回归、Debug 构建、设计 token 检查通过。测试使用 OkHttp 拦截器固定响应，无实际上传、会议创建或麦克风调用。本批不包含录音 UI、持久恢复或前台服务，继续在下一批实现。
