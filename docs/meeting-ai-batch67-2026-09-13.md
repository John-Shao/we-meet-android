# 第 67 批：通知中的精确纪要版本链接

接入 `https://<会议域名>/meeting/records/<record UUID>?summary=<version UUID>`。仅接受配置的 HTTPS origin、规范 UUID 与唯一 summary 参数，拒绝用户信息、异常端口、片段、重复或无效版本参数。链接只选择记录与版本，读取仍由当前登录用户的实时权限决定。

冷启动链接可在本次进程内等待登录；不存储正文或远程 API 地址。详情固定读取该版本，找不到或失权时显示不可用，用户主动点击「全部版本」后才解除选择；不回退到房间最新纪要。既有列表入口仍正常显示全部版本。

原生 App Link 使用随 `WE_MEET_RECORDS_NATIVE` 关闭的 activity-alias；默认 false 时不接管原网页链接。域名验证依赖部署端的 assetlinks.json 和应用签名，用户部署后验证系统跳转与冷启动登录流程。

验证：21 项 JVM 测试（记录仓库 16、链接解析 5）、7 项隔离模拟器 Compose 测试、Debug／测试 APK 构建与设计 token 检查通过。检查了合并 manifest 中 alias 默认 disabled。所有数据为固定样本，无实际通知发送或服务调用。实际域名验证与账户登录联调未执行。
