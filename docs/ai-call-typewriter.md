# AI 通话逐字输出

AI 回复收到模型增量文字后就在当前气泡中逐字追加，不等待整段回复结束。用户转写和历史详情直接显示完整文字，图片展示保持原行为。动画约每 25 毫秒推进一次，积压较长时加快；按完整字符边界显示，避免把表情或组合字符拆开。旋转保留已经展示的位置，向上翻阅时不自动回到底部，“回到最新”恢复跟随。

AOQ 与 WebRTC 共享 `OmniTranscript`，接收 `response.audio_transcript.delta` / `response.text.delta`，按消息项和内容槽更新同一行，按事件 ID 去重。一个内容槽只拼接一种输出流，避免文本与语音转写重复。完整事件校正最终文字；取消响应结束时保留已收到的片段，最终事件之后迟到的增量不再追加。用户转写仍以完成事件为准，沿用原排序和每次通话标识隔离。

`isStreaming` 是当前通话的内存标记，不增加数据库列或后端接口。逐字动画只影响展示，不把每帧状态写入历史；完整回复写入本机历史，提前挂断或断线时保存已收到的文字快照。关闭保存不影响实时展示。根据[阿里云服务端事件说明](https://help.aliyun.com/zh/model-studio/server-events)，增量事件携带新增文字，完成事件携带完整转写。

2026-10-10 验证：105 项助手单元测试通过，涵盖增量拼接、重复事件、完整文字校正、内容槽分离、取消后的文字保留、工具文字过滤、大小限制、时间戳及旧通话隔离。Debug App、AndroidTest、Release Kotlin 编译和设计规范检查通过。Pixel 7 Pro（Android 17 / API 37）三项页面回归通过，包括逐字追加、完整家庭表情、保存状态恢复、增量更新时手动翻阅不跳动、视频聊天面板、图片放大和挂断保留。

Pixel 真实连接三项测试通过：AOQ、WebRTC 分别观察到 19 和 24 次流式转写回调；连续／重复／回复结束时打断后，原连接继续给出文字及语音。AOQ 生产 ViewModel 完成三轮合成语音，确认打开历史时音频继续、关闭保存仍显示当前文字、旧增量隔离，并通过注入未完成文字回调验证挂断时本机历史保留快照。真实连接使用合成输入，未宣称真人麦克风或弱网验收。
