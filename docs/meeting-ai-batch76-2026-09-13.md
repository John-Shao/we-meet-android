# 第 76 批：原生录音转写操作与实时文字

原生录音页接入独立 ASR：录制中可手动开启实时转写，封存后可手动转写；不完整音频的允许选项默认关闭。状态每 5 秒读取，实时确认文字每 3 秒读取，默认最新 50 条并支持回看/跟随最新；读取失败隐藏旧正文并等待手动刷新。页面退出前台后停止读取和关闭请求日志，恢复时重新检查。

付费操作使用第 75 批加密持久化日志。结果未知时只提供核对原请求，保持相同幂等键、正文和目标；重返页面不会自动发送。关闭新建能力后仍可核对已保存请求。取消只作用于当前精确任务，取消结果未知时刷新状态，不自动创建新任务。

验证：5 项新增 Compose/真实 Keystore 测试，加上 5 项录音 UI 和 7 项记录 UI 回归，共 17 项在隔离模拟器通过。覆盖显式创建、required null、取消、未知结果恢复、能力关闭后的原请求、分页、读取失败及后台停止刷新。Debug/test APK 与设计 token 检查通过；就绪、预览、未知结果三种截图已检查。测试使用假 API、无真实网络或模型调用。开关仍默认关闭，实体设备录音和服务端联调由部署测试验证。

下一批继续原生分阶段总结与自动纪要控制；完整技术评审尚未完成。
