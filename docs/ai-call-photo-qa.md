# AI 电话拍图问答

通话时将后置镜头对准物体，说“帮我看”“帮我看看这是什么”“帮我看这个怎么用”。实时 Omni 理解本轮语音，调用独立的 `take_photo(question)` 工具。语音通话临时获取一张新照片并释放摄像头；视频通话使用当前镜头的新帧，保持视频模式。“打开摄像头／关闭摄像头”仍通过 `set_camera_enabled` 切换模式。

照片在内存中旋转并编码为不超过 512 KB 的 JPEG，不写相册和聊天历史。App 将照片和模型从语音理解出的完整问题发送到绑定当前通话租约的后端视觉接口，工具结果由原实时模型使用当前音色回答。视觉接口接收语义问题和图片，原始语音继续由实时 Omni 接收，未重复发送原始 PCM 给视觉模型。

拍图复用摄像头权限和前台服务控制器，与模式切换共享串行锁；页面不在前台或手机锁定时拒绝新的拍图。拍图显示“正在拍图并分析…”。重复消息 ID 不重复执行，同一模型响应最多拍一次；新的用户轮次可以再次拍图。打断或挂断取消待完成工具，旧通话结果不会写入新通话。设备无法确认摄像头释放时，关闭整个媒体拥有者，避免残留采集。

后台三条系统提示词为 `call.tool.photo`、`call.tool.description.take_photo`、`call.photo_qa`。先部署后端及数据迁移 0200，再安装客户端。视觉模型默认 `qwen3.8-flash`，可通过 `AI_CALL_PHOTO_MODEL` 配置。图片不被加入工具结果、日志或数据库；文字回答继续沿用原聊天记录规则。HTTP 调用禁用自动重试、重定向和缓存。

2026-10-10 验证：Android 672 项单元测试、Debug 编译、Release Kotlin 编译、设计规范和五种语言资源检查通过；后端 179 项相关测试通过，完整 Release guard 通过。JPEG 编码设备测试覆盖颜色、旋转后尺寸和大小限制；聊天页面及编码设备回归共 3 项通过，320 dp 小屏的拍图提示与通话控制在深浅色布局均通过断言和截图检查。权限拒绝、后台、挂断、打断、重复工具和旧结果隔离由单元测试覆盖。

真实生产接口：荣耀 AMM-AN00 的 AOQ 合成语音通过“帮我看→拍图→视觉回答→原音色播报→打开摄像头→视频拍图→关闭摄像头”，验证同一连接、同一租约及模式保持；API 29 模拟器 WebRTC 合成语音拍图问答通过。语音为测试资产，摄像头使用实际 Camera2，未保存拍摄图片。未宣称完成真人麦克风、蓝牙或弱网验收。
