# AI 电话拍图问答

通话页面不显示“停止”按钮。开麦时可通过语音打断 AI；语音通话不显示“说话或点击打断”常驻提示。

通话时将后置镜头对准物体，说“帮我看”“帮我看看这是什么”“帮我看这个怎么用”。实时 Omni 理解本轮语音，调用独立的 `take_photo(question)` 工具。语音通话临时获取一张新照片并释放摄像头；视频通话使用当前镜头的新帧，保持视频模式。“打开摄像头／关闭摄像头”仍通过 `set_camera_enabled` 切换模式。

照片在内存中旋转并编码为不超过 512 KB 的 JPEG。拍摄完成后，同一张照片作为右侧图片消息插入本轮问题与 AI 回答之间，可点击全屏查看、双指缩放和平移、双击放大／还原，返回先关闭预览，保持通话。挂断保留当前记录，新通话清空。App 将照片和模型从语音理解出的完整问题发送到绑定当前通话租约的后端视觉接口，工具结果由原实时模型使用当前音色回答。视觉接口接收语义问题和图片，原始语音继续由实时 Omni 接收，未重复发送原始 PCM 给视觉模型。

关闭历史保存时，照片仅保留在当前通话内存中。开启保存时，JPEG 保存到当前账号的 `noBackupFilesDir` 私有目录，SQLite 保存相对文件名；旧文字历史通过新增可选列兼容。历史列表不加载所有图片字节，仅在显示图片时后台解码。删除、按类型清空、200 次会话保留规则淘汰记录时，图片文件一并清理。图片不写相册或后端历史，历史复制和分享仍导出文字，用本地化的图片标记替代照片；总结接口只接收文字行。

拍图复用摄像头权限和前台服务控制器，与模式切换共享串行锁；页面不在前台或手机锁定时拒绝新的拍图。拍图显示“正在拍图并分析…”。重复消息 ID 不重复执行，同一模型响应最多拍一次；新的用户轮次可以再次拍图。打断或挂断取消待完成工具，旧通话结果不会写入新通话。设备无法确认摄像头释放时，关闭整个媒体拥有者，避免残留采集。

后台三条系统提示词为 `call.tool.photo`、`call.tool.description.take_photo`、`call.photo_qa`。先部署后端及数据迁移 0200，再安装客户端。视觉模型默认 `qwen3.8-flash`，可通过 `AI_CALL_PHOTO_MODEL` 配置。图片不被加入工具结果、日志或后端数据库；文字回答继续沿用原聊天记录规则。HTTP 调用禁用自动重试、重定向和缓存。
