# 参考飞书，支持在私聊（一对一）会话、和群聊会话中快速查看和创建日程。

1. 单聊 / 群聊一键约会
聊天窗口右上角「查看日历」 / 「群成员日历」，侧边直接展示双方 / 全员本周时间轴，拖动空白时段就能新建日程，不用切换页面。
例如，在图 2 中，你和李梓昂单聊时，右侧同步显示两人忙闲，直接选中共同空闲时段发起 11 点会议。

2. 日程消息互通
创建完成自动在会话发送日程卡片，所有人收到飞书通知；修改时间 / 新增参会人实时推送变更提醒。

3. 群成员批量排期
群日历功能一键查看所有群成员忙闲，自动筛选所有人都有空的时间段，解决多人约会反复沟通的痛点。
