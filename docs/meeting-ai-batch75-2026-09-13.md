# 第 75 批：原生转写协议与持久付费意图

新增独立录音 ASR 的状态、创建、取消和实时确认文本预览 API。私有 HTTP 客户端沿用禁止重定向/缓存/日志、20 秒超时和不自动连接重试。缺失能力默认不可用；进度、代次、分页、精确 job 和时间坐标经过校验，预览不会被当成正式发布原文。首次创建显式发送 expected_job_id:null，避免默认 Moshi 省略 null 导致契约不匹配。

MeetingIntentStore 在 noBackupFilesDir 内以账号 Keystore AES-GCM 加密持久保存请求键和正文，与音频历史清理独立。最多 128 个未解决请求，不自动过期或覆盖；只有精确匹配的已确认/明确拒绝请求可清除。CaptureTranscriptionCoordinator 在发送付费请求之前保存意图；未知结果、超时、429 和服务器错误保留原键/正文，即使 UI 选项改变也只重放原请求。打开或查询日志本身不会触发请求。

验证：7 项仓库 JVM 测试、4 项真实 Keystore/SQLite 模拟器测试、Debug/test APK 与设计 token 检查通过。覆盖 required null、能力缺省、错代次/分页/任务、账号切换、取消、失败不自动重试、重启后复用请求、429/409、旧确认不能清新意图及存储上限。测试无真实网络或模型调用。录音页转写操作与实时文本下一批接入。
