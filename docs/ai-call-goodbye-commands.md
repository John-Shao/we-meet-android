# 告别结束 AI 通话

结束通话指令支持“再见”“拜拜”及“再见了”“拜拜了”“那就再见吧”“好啦，拜拜”“我们下次聊，再见”等自然派生说法。用户本轮向 AI 告别就表示明确授权挂断，无需同时说“结束通话”。调用现有 `end_call({})` 工具直接结束当前语音或视频通话，释放媒体、前台服务和租约，不只生成口头告别。

否定、询问、假设、翻译、引用、角色扮演或图片中的文字不触发挂断。例如“不要说再见，我们继续聊”“拜拜是什么意思”“把再见了翻译成英语”“如果我说拜拜会怎样”“他说了再见，但我们继续聊”。AI 自己的告别不会触发工具。上一轮解释过告别词，不影响本轮用户独立告别的判定。关闭摄像头、暂停说话和拍图仍沿用各自行为。

规则由后台两条提示词 `call.tool.end_call`、`call.tool.description.end_call` 控制。执行后端 `python manage.py extend_end_call_commands` 追加扩展，保留原正文、启停状态及其他提示词，可重复执行。新会话读取规则，不需更新 APK、重启服务或数据库迁移。

设备回归入口为 `OmniEndCallLiveTest` 的五个新增用例，四个 AOQ 合成语音用例覆盖四种告别、否定、词义询问、翻译请求和视频模式；一个 WebRTC 文本用例覆盖假设、引用及派生告别。断言实际挂断工具仅调用一次、UI 正常结束、客户端关闭、资源释放和租约关闭，不能用连接失败代替通过。合成语音为 Microsoft Huihui Desktop / 16 kHz PCM16；对应文字见 `app/src/androidTest/assets/hangup-goodbye-speech.txt`，不代表真人麦克风或弱网验收。

2026-10-10 生产提示词已更新；61 项相关后端测试、Android 测试 APK 编译、设计规范检查和 Pixel 7 Pro 五项回归通过（64.288 秒）。后台规则生效于新通话，手机现有 APK 可直接使用。

后续稳定性复测未全部通过：八项真机回归通过七项，“拜拜”有一次仅回复告别语而未挂断；随后四次独立通话对照再次复现。已确认失败时语音转写正确、强化规则已加载，但模型未生成任何工具请求。当前提示词方案仍有漏执行，详见[定位记录](ai-call-goodbye-diagnosis.md)。
