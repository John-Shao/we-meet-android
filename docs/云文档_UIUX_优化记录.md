# 原生云文档 UI / UX 优化

日期：2026-09-07。范围：Android 原生列表、阅读、搜索、评论、分享、版本、子文档、移动及标题表单。

## 设计取舍

- 延续 `core-design` 的 Material 3 色彩、字号、间距和触控尺寸，不另设 Docs 主题。
- 阅读以正文为主。标题与正文一起滚动，离开可视区后才进入顶栏；底栏只保留一个主动作“编辑”，评论、版本、分享使用图标与文字入口。
- 列表突出文档名称和更新时间。普通文档把收藏放入更多菜单，已收藏的文档仍显示星标。主页增加快捷筛选、当前排序和带文字的新建入口，列表尾部为悬浮按钮留出空间。
- 弹层提供统一标题、文档上下文和明确关闭按钮。长内容独立滚动，移动确认按钮与评论输入框保持可达；权限、评论动作和表情在窄屏按需换行。
- 新建、重命名、移动均在成功后关闭；失败保留输入或目标并显示错误，提交中显示进度且防止重复提交。重命名默认选中原标题，没有修改时禁用保存。

## 交互调整

| 入口 | 行为 |
|---|---|
| 搜索 | 自动聚焦、键盘搜索动作、清空按钮、输入引导；防抖期间显示加载而非短暂的无结果；结果行与主页保持一致 |
| 评论 | 未解决/已解决数量，独立空态；讨论边框和展开指示；折叠长评论摘要；删除收进更多菜单，保留二次确认；发送中禁用编辑，避免响应清掉新输入 |
| 评论草稿 | 继续使用已有文档级草稿存储，关闭面板不会丢失；回复仍独立保存 |
| 分享 | 复制链接、范围说明、权限选项换行；保存权限时禁用切换；成员角色带下拉与选中标记；移除成员先确认 |
| 成员与邀请 | 搜索失败可重试；姓名与邮箱分行；邮箱键盘及格式校验；成员操作期间显示进度；失败保留表单 |
| 版本 | 说明与明确空态；整行进入预览；长列表独立滚动，保留分页入口 |
| 子文档 | 统一文件图标、两行标题、进入指示和普通分页文案 |
| 移动 | 加载失败可重试、无可用目标空态；选择行满足触控尺寸；树缩进封顶，避免深层节点挤出屏幕 |
| 编辑器不可用 | 使用用户可理解的重试/返回阅读文案，部署与协议细节保留在技术文档 |

## 适配与验证

新增文案覆盖中文、英文、德文、法文、荷兰文。样式复用主题语义颜色；交互图标有可读描述，标题提供 heading 语义，讨论展开提供操作描述。

本地 Pixel 8 / Android 16，演示账号 W009：

- 主页、阅读、评论、分享、版本空态实机走查。
- 评论软键盘弹出后输入框和发送入口可见；草稿关闭重开保留，测试草稿随后清空，未发表测试评论。
- 新建断网失败后标题保留，出现错误与重试入口；测试后关闭表单并恢复网络，未创建测试文档。
- 成员移除确认可以取消，未修改已有成员或链接权限。
- 搜索恢复网络后重试成功，清空后回到输入引导。
- 深色与 1.5 倍字体下，阅读操作可达、分享选项换行且长面板可滚动。
- 横竖屏切换暴露了宿主嵌套抽屉偏移错误；已限制抽屉最大宽度，并在宽度变化、新锚点就绪后关闭抽屉。验证旋转不再误展开、横屏手动开关可用、展开时旋转能正确回到列表。
- 重命名自动选中原标题，未修改时保存禁用，取消后文档标题不变。

构建检查使用 `:feature-docs:testDebugUnitTest :app:assembleDebug checkDesignTokens`，14 项已有单元测试通过；UI 验证不向已有文档写入内容。

## 验收边界

此轮不替代编辑器协议 v2 的前端部署与联调。历史版本服务当前返回空列表，只验收了版本入口、空态及列表实现，未将真实历史预览/恢复记为通过。未进行屏幕阅读器全流程、所有语言和所有折叠屏设备矩阵验收；新增表单成功写入及失败路径仍需在发布测试环境做完整业务回归。
