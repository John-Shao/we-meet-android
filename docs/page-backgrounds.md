# 页面层级与背景分区

浅色主题以「消息」一级页和「新建日程」二级页为参照：

| 页面层级 | 顶部固定区域 | 下方滚动区域 |
| --- | --- | --- |
| 一级：六个主模块 | `colorScheme.background`，浅灰 | `colorScheme.surface`，白色 |
| 二级及更深：新建、详情、设置等 | `colorScheme.surface`，白色 | `colorScheme.background`，浅灰 |

- 一级页面的浅灰头部衔接系统状态栏，白色内容底衔接底部模块导航栏。
- 日历例外：横向滑动的日期栏使用白色内容底，颜色分界在日期栏上方；会议室日期栏同样处理。
- 二级及更深页面的系统状态栏与白色头部衔接。常规页面使用 `WeMeetTopBar` 的默认底色，不设透明头部。
- 灰色滚动区域中的表单卡片、信息卡片可保持白色；不把卡片颜色改成区域底色。
- 使用已有主题 token，深色模式跟随对应主题值；不用硬编码的白色或灰色。
- 视频、摄像头预览等媒体画面，以及封面图片等专用内容，使用各自的语义色。
