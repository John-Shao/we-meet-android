# 第 74 批：原生 AI 录音页面与通知返回

会议首页的 AI 录音入口受 WE_MEET_CAPTURE_NATIVE 控制，默认仍关闭。新增独立二级页，白色主题表面顶栏、灰色滚动区，隐藏模块导航。页面接入本地恢复、麦克风申请、显式开始/续录、即时暂停、结束确认、补传与完成保存；已经进入封存流程时隐藏续录，只提供完成保存。权限或网络错误有明确重试入口。

页面仅 RESUMED 时绑定并读取服务，离开/后台清除私有呈现；已启动前台录音继续运行，返回重新绑定同一会话。通知携带当前账号返回录音页，账号不同的旧通知不导航；通知导航本身不会开麦。通知关闭时页面说明从应用内暂停或结束。原生会议记录开关开启后，已保存录音可跳到对应 record。

验证：5 项纯 Compose 交互测试、1 项真实页面/服务生命周期合成音频集成测试、7 项会议记录 UI 回归通过。集成测试覆盖显式开始→退后台→回前台→暂停→确认结束→保存。Debug/test APK、设计 token 检查通过；开始、录音、深色恢复及错误态截图已走查。测试使用断网只读模拟器和合成音频，没有实际开麦或服务器写入。

剩余：录音页实时转写、分阶段纪要、原生回听与任务/交付控制继续接入。当前“保存”只确认音频封存，不伪称已生成转写/纪要。真机锁屏、蓝牙、来电及通知冷启动导航仍待部署测试。
