# 第二十六批：批量校对

原文工具栏增加“批量查找替换”：整条已保存记录字面匹配、逐段预览、明确确认，以及最近 10 次操作的安全撤回。入口仅由服务端 `batch_correct` 授予，旧后端缺省隐藏。单批最多 100 段；未保存草稿、ASR 原文和旧纪要快照不会自动修改。

提交沿用加密的 MeetingIntentStore，按账号和记录隔离；请求结果未知时重启可恢复原请求，不自动提交。权限暂时失效不会清除未知结果标识。恢复存储失败时阻止新写入并允许重试。撤回必须二次确认，服务端拒绝覆盖后续校对。网络失败时可关闭面板，稍后继续处理。

验证：45 项相关单元测试通过；Pixel 8 / Android 16 的 5 项仪器测试通过，包括预览不提交/输入变化、响应丢失同请求重试、409、两步撤回、加密标识跨仓库重建和账号隔离。正式分发及本批生产验收待完成。
