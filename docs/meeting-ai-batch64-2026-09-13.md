# 会议 AI 第 64 批：Android 统一记录读取基础

新增 `MeetingRecordApi` 和按账号隔离的 `MeetingRecordRepository`，读取统一资料库、准确记录、分阶段纪要与不可变原文引用，复用主应用鉴权。现有房间详情暂保留，下一批接入新资料库和纪要页面。

- 记录和快照只接受 UUID；房间重复使用导致解析冲突时保留 409，不降级读取房间最新纪要。
- 分页使用不透明游标参数，固定 API 源站，每页最多 30 项；不跟随服务端提供的任意 URL。
- 权限缺省为关闭。读取原文前重新检查当前能力，引用必须匹配段落、版本及起止时间。账号切换后的响应丢弃，协程取消正常传播。
- 专用 HTTP 客户端禁用重定向、磁盘缓存和调试日志；所有记录读取发送 no-store。现有调试日志同时补充鉴权及 Cookie 请求头脱敏。
- DTO 保留实时、速记、最终版本与正在识别状态，不把进度标成完整覆盖。

验证：12 项 JVM 契约/仓储测试、Kotlin 编译及设计规范护栏通过；所有 HTTP 使用本地拦截夹具。无真实服务访问、模型调用或账号内容。Debug APK 构建通过；设备和实际后端验证由用户部署测试。此批尚不包含原生录音、前台服务、翻译或新页面。
