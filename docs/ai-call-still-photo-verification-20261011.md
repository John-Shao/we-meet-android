# “帮我看”静态拍照验证（2026-10-11）

本次候选将视频取帧替换为 Camera2 原生静态 JPEG。最终同一份方向正确、sRGB、质量 92 的 JPEG 用于本机显示、历史记录与模型上传；不保存另一份高质量原图。兼容生产接口的 512,000 字节、1920 长边与 2,100,000 像素限制，复杂画面超过大小限制时等比缩小。

实机为已连接的 Pixel 7 Pro（Android 17），不是前期荣耀设备。后置原生 JPEG 为 4032×3024，最终共享 JPEG 为 1254×1673；前置原生 JPEG 为 3440×2448，最终为 1222×1717。上述实机拍照记录 `metered=true`，Camera2 HDR 场景不可用；不能据此宣称具有 Pixel 系统相机 HDR+ 效果。模拟器前置相机出现 `metered=false` 的有界等待回退，拍照及视频恢复仍通过。

模拟器初始相机／编码／UI 共 7 项通过（61.830 秒），加入取消和前置镜头断言后重跑相关 2 项通过（35.960 秒）；Pixel 初始 4 项通过（25.779 秒），补充断言后相关 2 项通过（23.819 秒）。两项真实模型测试通过（75.626 秒）。真实链路首轮因为模拟器过期登录凭证未能建连，已保留失败记录；测试明确使用用户授权的演示账号重新登录后通过，并补充上传图片和本地图片的字节比对。

## 交付与实机验收边界

内部 APK、签名／对齐检查、源码快照哈希、单元测试 XML 和上述日志保存于 `release/0.3.0-work.2-still-photo-20261011/`，详见目录中的 `candidate.json`。Release 为内部签名、非 debuggable，可覆盖安装此前内部包；没有生产后端改动、部署或数据库迁移。

自动化证明拍照流程、图像契约和连接恢复，不证明同场景画质已经达到系统相机。仍需用户在相同位置、镜头和光线下对比天空高光、建筑文字、树叶和室内近物；尤其检查亮暗差异大的场景。Pixel 的本次硬件验证不替代荣耀设备验收，WebRTC 本地原生媒体生命周期测试也不代表本次完成了真实模型 H264 视频全链路验收。

回退需同时恢复旧的 `CallPhotoCapture` 与两客户端的视频取帧入口。后端图片契约和历史 JPEG 格式保持兼容，无需修改 API Key 或迁移已有会话记录。
