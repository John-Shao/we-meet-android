# Android 参会者身份识别代码走查

日期：2026-10-12；基线 `main` / `53d5a721`。

## 修复

- 存在未知提交命令时，普通 404 也必须阻止重试和取消。只有带 request key 的读取返回 404 且 code 为 `voiceprint_identity_request_unavailable`，才表示原批次尚未创建，可由用户显式重试同一命令。私有客户端有界解析错误 JSON，异常正文不进入控制器状态。
- 只有提交请求明确返回 400 才清除原命令；读取的 400 保留原 key 和完整 ID 命令，避免未知提交丢失后重复创建任务。401／403／404／410 隐藏私有结果并阻止写入，409 继续使旧命令失效。
- 导入预检目录失败清空旧姓名；库读取失败同时清空组织目录、分页及人员页，并阻止在途人员响应重新发布姓名。保留用户选择的 ID，只有后续有效读取的姓名才可重新显示。

上述问题由 5 个新增 JVM 回归在修复前实际复现。补充用例还覆盖明确拒绝、故障恢复及经过核验的批次缺失仍可显式重试；契约测试通过实际 Retrofit／OkHttp 响应验证 404 错误码、403、无 key、无效和超限 JSON 的处理。
