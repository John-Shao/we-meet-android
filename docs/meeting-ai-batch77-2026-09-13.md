# 第 77 批：原生分阶段总结与自动纪要协议

新增 MeetingSummaryApi / Repository，接入精确记录的总结进度、生成/重新生成/重试，以及自动纪要状态与开启/停止。使用私有 HTTP 客户端，缺省能力关闭，严格检查阶段、任务代次、输入版本、分块进度和自动化命令结果。请求显式发送 nullable job/attempt；自动化重放区分原命令结果与当前状态，避免把后续停止误认成开启失败。

MeetingSummaryCoordinator 复用账户隔离的 Keystore/SQLite 日志，总结与自动化意图各自存储；发送前持久化，结果未知或限流保持原键/正文，明确拒绝只清除对应意图，不自动重试。无效本地请求在写日志前拒绝。

验证：7 项新增 JVM 协议测试、7 项 ASR 回归；4 项新增协调器测试与 4 项日志回归在隔离模拟器通过。Debug/test APK、设计 token 检查通过。测试假接口，无实际模型、通知或共享动作。下一批接入页面操作、实时/速记内容及自动纪要授权。
